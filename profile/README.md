# Krateo PlatformOps has moved

This organization is the **legacy home** of Krateo PlatformOps.

- The main repository has moved from `krateoplatformops/krateo` to **[krateo-platformops/krateo](https://github.com/krateo-platformops/krateo)**.
- The whole codebase now lives in the new organization: **[github.com/krateo-platformops](https://github.com/krateo-platformops)**.
- The repositories here contain the components up to **Krateo 3.0.x**. Use them only if you run 3.0.x or earlier.

Documentation: [docs.krateo.io](https://docs.krateo.io) · Questions: [GitHub Discussions](https://github.com/krateo-platformops/krateo/discussions)
